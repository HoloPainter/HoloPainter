# Transitive Dependencies

This document currently identifies the direct dependencies declared by HoloPainter and known bundled third-party assets.

Rust packages may themselves depend on additional third-party packages.

The exact transitive dependency graph depends on the versions selected by Cargo. Therefore, the complete license set for a specific HoloPainter release must be determined from that release's committed `Cargo.lock`.

Before publishing a release, the dependency graph should be audited using a tool such as `cargo-deny`, for example:

```bash
cargo deny check licenses
```

The release process should ensure that:

1. `Cargo.lock` is committed to the repository.
2. The complete dependency graph has been checked for license compatibility.
3. Required copyright notices and license texts are preserved.
4. Dependencies with unacceptable or unexpected licenses are removed, replaced, or explicitly reviewed.
5. This document is updated when dependencies or bundled assets change.
